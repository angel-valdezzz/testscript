# Roadmap y alcance actual

Estas entradas son intenciones; no representan funcionalidades implementadas ni fechas prometidas.

## 0.1.0 — primera versión funcional

Implementado: gramática/parser, intérprete, contratos tipados, records, fn/flow, test/fixture/data/step, excepciones básicas, tags, imports, CSV/JSON/YAML locales, diagnósticos CLI, adaptadores Web opcionales, HTTP, HTML/JSON/JUnit y MkDocs bilingüe.

## Siguientes iteraciones

1. Fortalecer gramática, diagnósticos, inferencia y análisis de retornos con suites reales.
2. Retry de assertions con semántica segura, evidencia automática y eventos más completos.
3. Locators/frames/ventanas y HTTP/schema según casos reales.
4. Formatter, sintaxis para VS Code y evaluación de LSP.
5. Paralelismo controlado y nuevos scopes de fixtures conservando aislamiento.
6. Evaluar adaptadores Mobile e integraciones estables con reporters.

## Antes de 1.0

Estabilizar sintaxis y contratos públicos, documentar compatibilidad, validar instalación por OS/Python y demostrar suites Web/API mantenibles. La versión 0.1 no significa madurez de producción.

## Publicación

La distribución se llama `testscript-lang`, sujeta a registro. `.tscr` y `tscr` son identificadores del producto. Publicación PyPI, creación remota GitHub y activación Pages deben verificarse antes de describirse como completadas.
